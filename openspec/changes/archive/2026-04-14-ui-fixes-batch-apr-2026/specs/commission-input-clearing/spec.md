## ADDED Requirements

### Requirement: 佣金率输入框允许清空后重新输入
佣金编辑表单中的佣金率输入框 SHALL 允许用户完全清空输入框内容后重新输入新值，不得在输入过程中强制补零。

#### Scenario: 用户清空佣金率输入框
- **WHEN** 用户在佣金编辑对话框中选中输入框内容并删除全部内容
- **THEN** 输入框 MUST 显示为空白（空字符串），不得自动填充 "0"

#### Scenario: 用户在清空后输入新数字
- **WHEN** 用户清空输入框后输入 "12"
- **THEN** 输入框 MUST 显示 "12"，而非 "012"

#### Scenario: 用户提交含空输入框的表单
- **WHEN** 用户提交表单时某个佣金率输入框仍为空
- **THEN** 系统 MUST 将空值作为 0 处理并提交
