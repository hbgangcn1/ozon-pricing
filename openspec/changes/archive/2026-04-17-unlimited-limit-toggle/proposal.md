# Proposal: 套餐编辑 — 计算次数/物流模板支持"无限"开关

## 背景

在 `PlanManagementPage.jsx` 的套餐编辑表单中，"计算次数"（`calcLimit`）和"物流模板"（`logisticsTemplate`）目前是纯数值输入框，用户需要手动输入 `-1` 来表示"无限次"。这不直观。

## 目标

为这两个字段各增加一个"无限"开关（Switch）：
- **开启"无限"** → 隐藏数值输入框，值设为 `-1`
- **关闭"无限"** → 显示数值输入框，用户输入具体数值

## 范围

- **仅前端**：`frontend/src/pages/PlanManagementPage.jsx`
- 后端已支持 `-1` 表示无限，无需修改

## 设计

### UI 变化（PlanEditForm 组件，第 276-292 行）

**改前：**
```
⚙️ 功能配置
┌──────────────┐  ┌──────────────┐
│ 计算次数      │  │ 物流模板      │
│ [-1_________] │  │ [-1_________] │
└──────────────┘  └──────────────┘
```

**改后：**
```
⚙️ 功能配置
┌──────────────────┐  ┌──────────────────┐
│ 计算次数          │  │ 物流模板          │
│ [✓] 无限          │  │ [✓] 无限          │
│  (输入框隐藏)      │  │  (输入框隐藏)      │
└──────────────────┘  └──────────────────┘

┌──────────────────┐  ┌──────────────────┐
│ 计算次数          │  │ 物流模板          │
│ [ ] 无限          │  │ [ ] 无限          │
│ [50__________]   │  │ [3___________]   │
└──────────────────┘  └──────────────────┘
```

### 逻辑

1. 表单初始化时：检测 `calcLimit === -1` → 开关开启，隐藏输入框
2. 切换为"无限" → `calcLimit` 设为 `-1`，隐藏输入框
3. 切换为"有限" → `calcLimit` 恢复为上一次的数值（或默认值如 `10`），显示输入框
4. `logisticsTemplate` 同理

### 不变的部分

- 后端 API（`calc_limit: int`，`-1` = 无限）
- `PlanCard` 展示组件（已正确显示"无限"）
- `SubscriptionPage` 用户端展示
- 数据库结构
